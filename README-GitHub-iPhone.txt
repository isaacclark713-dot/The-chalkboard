Call Sheet PWA — GitHub Pages Upload

1. Unzip this folder.
2. Create or open your GitHub repository.
3. Upload the unzipped files, not this ZIP.
4. Commit the changes.
5. Go to Settings → Pages.
6. Source: Deploy from a branch. Branch: main. Folder: /root. Save.
7. Open the Pages link in Safari on iPhone.
8. Tap Share → Add to Home Screen.

Important storage note:
GitHub hosts the app files only. Each user’s saved base playbook, corrections, custom database uploads, scout data, and in-game tracking are stored locally in that user’s browser via localStorage. This means their data stays consistent on that same device/browser/URL, but it does not automatically sync to another phone or browser.

Updating:
Upload these new files over the old repo files. The service worker cache version is changed, so phones should pick up the new app after Safari reloads the site or the Home Screen app is reopened.
